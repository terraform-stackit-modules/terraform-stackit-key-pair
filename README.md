# Terraform STACKIT Key Pair module

Terraform module which manages an [SSH key pair](https://registry.terraform.io/providers/stackitcloud/stackit/latest/docs/resources/key_pair) on [STACKIT](https://www.stackit.de/en/), used to authenticate to STACKIT servers.

This repository is not from the official STACKIT organization.

## Usage

```hcl
module "key_pair" {
  source  = "terraform-stackit-modules/key-pair/stackit"
  version = ">= 1.0.0"

  name       = "my-key-pair"
  public_key = file("~/.ssh/id_ed25519.pub")

  labels = {
    managed_by = "terraform"
  }
}
```

Pass the resulting `name` to the compute module to boot a server with this key:

```hcl
module "compute" {
  source = "terraform-stackit-modules/compute/stackit"
  # ...
  keypair_name = module.key_pair.name
}
```

## Notes

- Only the **public** key is an input — never commit a private key.
- `public_key` must be an OpenSSH public key (`ssh-rsa`, `ssh-ed25519`, or `ecdsa-*`); this is validated at plan time.
- `stackit_key_pair` is account/region-scoped and does not take a `project_id`.
- Set `create_key_pair = false` to disable the resource (e.g. to reference an existing key pair elsewhere).
